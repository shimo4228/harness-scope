## 計画への影響

計画は「ネイティブ設定で届かない残りを Mod が受け持つ」としていた。2.1.287 では、user の skill・plugin 単位の skill と
agent・`~/.claude/rules`・ツールが、どれも project の settings で外せる。ネイティブに無いのは次の 3 つだけ:

- repo 間で共有する名前付きのまとまり（各 repo の settings に書き写す）
- allowlist（あとから global に足した skill は、denylist に足すまで執筆 repo にも入る）
- plugin の skill を 1 つずつ外すこと（plugin 単位なら外せる）
