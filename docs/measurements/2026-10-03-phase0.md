## 計画への影響

計画は「ネイティブ設定で届かない残りを Mod が受け持つ」としていた。2.1.287 では、user の skill・plugin 単位の skill と
agent・`~/.claude/rules`・ツールが、どれも project の settings で外せる。ネイティブに無いのは次の 3 つだけ:

- repo 間で共有する名前付きのまとまり（各 repo の settings に書き写す）
- allowlist（あとから global に足した skill は、denylist に足すまで執筆 repo にも入る）
- plugin の skill を 1 つずつ外すこと（plugin 単位なら外せる）

設計への反映（r2 の「実装の形」を次のように直して実装する）:

- profile は `session.start` で読まない。最初に必要になった hook で読み込み、以後は同じ結果を待つ。`classic.SessionStart` の
  `clear` / `resume` で読み込み直す
- repo 自身の skill の判定は `session.usage` の source `projectSettings`。fs の `.claude/skills/` は一覧に載らない skill の
  ディレクトリも返す（今回 8 件のうち 1 件）ので、補助にとどめる
- allowlist・denylist の照合は一覧に載っている名前で行う（`session.usage` の名前ではない）
